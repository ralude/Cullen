# Sub-fase 14.03: Acceso cloud y recuperación

- **Fase:** [14 — Plataforma central en la nube](./README.md).
- **Estado:** Pendiente; fuera del MVP.
- **Dependencia:** [Persistencia PostgreSQL y API central](./14.02-postgresql-y-api.md) completada.

## Objetivo

Preparar un entorno central verificable antes de recibir inventario operativo.

## Tareas

- [ ] Configurar HTTPS y frontera pública de API, manteniendo PostgreSQL en acceso privado; provisionar entornos de prueba separados.
- [ ] Implementar autenticación/revocación aprobadas, restricciones de acceso y redacción de logs con correlación por nodo/sucursal.
- [ ] Configurar respaldo y retención, y ensayar restauración sobre una instancia aislada.
- [ ] Documentar despliegue de API, secretos, certificados y recuperación de configuración; las migraciones siguen siendo forward-only.
- [ ] Probar acceso sin sesión, sesión revocada, credencial de nodo de otra sucursal y fallos de persistencia.
- [ ] Registrar evidencias y tareas operativas pendientes para 17; no abrir un entorno operativo sin sus gates.

## Criterios de aceptación

- El endpoint público no expone credenciales, stack traces ni acceso SQL.
- Una credencial revocada pierde acceso y los intentos quedan auditados sin secretos.
- Se restaura el entorno central de prueba y se comprueba la integridad de sus referencias.
