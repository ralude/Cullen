# Sub-fase 17.02: Ensayos integrales de operación y recuperación

- **Fase:** [17 — Validación integral y despliegue gradual](./README.md).
- **Estado:** Pendiente; fuera del MVP.
- **Dependencia:** [Objetivos y matriz de validación](./17.01-objetivos-y-matriz.md) completada.

## Objetivo

Verificar el flujo local/nube/web con infraestructura representativa.

## Tareas

- [ ] Ensayar migración de una base con historia, actividad concurrente y varios almacenes.
- [ ] Ejecutar cortes de Internet, reinicios locales/cloud, ACK perdido, duplicados, contratos incompatibles y dependencias pendientes.
- [ ] Restaurar PostgreSQL a un punto anterior y reconstruir la proyección mediante el protocolo aprobado; probar insuficiencia de retención.
- [ ] Ensayar transferencias internas interrumpidas según el ciclo aprobado y verificar conservación/idempotencia.
- [ ] Probar aislamiento de usuarios/sucursales, revocación, caché SSR/cliente, dispositivos soportados y carga representativa.
- [ ] Medir los objetivos de 17.01; actualizar escenarios de fallo con evidencia y dejar visibles las limitaciones.

## Criterios de aceptación

- Los ensayos cumplen los objetivos fijados o registran fallos que bloquean la activación.
- Una restauración central y posterior convergencia no requiere alterar historia local.
- La UI refleja la degradación observada sin inventar actualidad o disponibilidad.
