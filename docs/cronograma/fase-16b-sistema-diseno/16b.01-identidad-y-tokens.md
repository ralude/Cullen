# Sub-fase 16B.01: Identidad visual y tokens

- **Fase:** [16B — Sistema de diseño propio de Cullen](./README.md).
- **Estado:** Pendiente; fuera del MVP.
- **Dependencia:** Fase 16 cerrada; pantallas y recorridos de consulta disponibles.

## Objetivo

Definir el lenguaje visual de Cullen a partir de los recorridos ya implementados.

## Tareas

- [ ] Auditar las pantallas de Fase 16 y explorar direcciones visuales con el responsable del producto.
- [ ] Definir tipografía, color, espaciado, densidad, jerarquía, bordes, iconografía, temas y movimiento reducido.
- [ ] Crear tokens semánticos de Tailwind/CSS para contenido, superficies, foco y estados; los estados operativos incluyen texto y no solo color.
- [ ] Definir patrones responsive para consultas densas en escritorio y lectura en móvil.
- [ ] Validar las propuestas en búsqueda, detalle, tabla y sincronización degradada; registrar aceptación de identidad visual.

## Criterios de aceptación

- Los tokens tienen significado y ejemplos, y permiten representar todos los estados de consulta.
- Escritorio y móvil comparten identidad sin perder legibilidad ni navegación.
- Existe identidad visual propia aprobada, más allá de sustituir un color de la plantilla.
