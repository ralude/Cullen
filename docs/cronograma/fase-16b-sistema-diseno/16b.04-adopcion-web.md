# Sub-fase 16B.04: Adopción integral en la Web App

- **Fase:** [16B — Sistema de diseño propio de Cullen](./README.md).
- **Estado:** Pendiente; fuera del MVP.
- **Dependencia:** [Documentación visual y pruebas](./16b.03-documentacion-y-pruebas.md) completada.

## Objetivo

Aplicar el sistema de diseño a la web y verificar que conserva su comportamiento.

## Tareas

- [ ] Migrar las pantallas de Fase 16 a tokens, componentes y patrones del sistema propio.
- [ ] Revisar búsqueda, detalle, móvil, tablas y estados degradados en conjunto con producto.
- [ ] Retirar duplicaciones visuales de la web que quedaron sustituidas por la biblioteca, sin refactor de negocio.
- [ ] Repetir pruebas de navegación, filtros, permisos, SSR/hidratación y aislamiento de sesiones tras la integración.
- [ ] Comparar rendimiento con la base de 16.04, resolver regresiones e incorporar documentación de adopción.
- [ ] Ejecutar build, lint, typecheck y pruebas; entregar evidencia visual y de accesibilidad para Fase 17.

## Criterios de aceptación

- Todas las pantallas del alcance usan el sistema propio; no quedan dos implementaciones activas del mismo patrón migrado.
- Los permisos, filtros, cantidades y estados de sincronización mantienen su semántica.
- Producto acepta la identidad y experiencia integradas, con verificaciones de calidad reproducibles.
