# Sub-fase 16.04: Calidad y entrega funcional de la web

- **Fase:** [16 — Web App interna con Next.js](./README.md).
- **Estado:** Pendiente; fuera del MVP.
- **Dependencia:** [Pantallas de consulta de inventario](./16.03-consulta-inventario.md) completada.

## Objetivo

Verificar la web funcional y establecer la base que recibirá el sistema de diseño.

## Tareas

- [ ] Ejecutar pruebas de navegador de login, búsqueda, filtros, detalle, vencimiento de sesión y estados degradados.
- [ ] Revisar teclado, foco, etiquetas, contraste, responsive, zoom y lectura de tablas con tecnologías de asistencia.
- [ ] Medir carga inicial y respuesta de búsqueda en los dispositivos/datos acordados; optimizar con herramientas adecuadas y evidencia.
- [ ] Ejecutar build de producción, lint, typecheck y pruebas de la web, además de las verificaciones del monorepo.
- [ ] Documentar composición cloud de Next.js/API, secretos y políticas de caché para el despliegue de Fase 17.
- [ ] Entregar un inventario de componentes/patrones existentes y necesidades visuales para 16B sin exigir su biblioteca aún inexistente.

## Criterios de aceptación

- Los recorridos autorizados funcionan en una build de producción con API central.
- Las pruebas detectan fugas de sesión, errores de hidratación y estados de stock engañosos.
- La web alcanza sus objetivos funcionales y de calidad; 16B puede evolucionar su presentación sin rehacer sus consultas.
