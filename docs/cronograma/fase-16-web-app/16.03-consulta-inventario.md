# Sub-fase 16.03: Pantallas de consulta de inventario

- **Fase:** [16 — Web App interna con Next.js](./README.md).
- **Estado:** Pendiente; fuera del MVP.
- **Dependencia:** [Sesión, consultas y estado de interfaz](./16.02-sesion-y-estado.md) completada.

## Objetivo

Construir búsqueda y detalle de inventario sobre la API central real.

## Tareas

- [ ] Implementar listado con búsqueda y filtros por sucursal/almacén, orden y paginación coordinados con el servidor.
- [ ] Implementar detalle por producto/almacén, lotes/vencimientos y kardex acotado con cobertura histórica visible.
- [ ] Mostrar cantidades con unidad y escala correctas; agregar solo productos y magnitudes compatibles.
- [ ] Presentar cero confirmado, carga inicial pendiente, información antigua, aplicación pendiente y error como estados distintos.
- [ ] Usar componentes base de shadcn/ui con Tailwind y registrar necesidades de patrones que consolidará 16B.
- [ ] Probar navegación, filtros, permisos, cargas lentas y fallos con el contrato real; los datos de ejemplo solo pertenecen a pruebas.

## Criterios de aceptación

- El personal consulta cantidades y movimientos sin escribir IDs internos a mano.
- Una sucursal sin carga nunca aparece con existencia cero inventada.
- Los resultados, totales y detalles se limitan al ámbito autorizado y al corte informado.
