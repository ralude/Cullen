# Sub-fase 12B.03: Capturas reproducibles

- **Fase:** [Fase 12B — Manual de usuario no técnico](./README.md)
- **Estado:** Planificada el 2026-09-09; ejecución pendiente.
- **Depende de:** [12B.01](./12b.01-inventario-de-interfaz.md) y
  [12B.02](./12b.02-lenguaje-y-plantilla.md).
- **Decisión que la origina:** D1 del [README de la fase](./README.md#decisiones-fijadas-el-2026-09-09).

## Objetivo

Producir una captura por pantalla —doce rutas más ingreso, cambio de PIN y activación de
credencial— de modo que cualquiera pueda volver a generarlas igual, y que ninguna filtre un dato
que no debería salir del nodo. Hoy el repositorio no tiene ninguna imagen: esta sub-fase también
decide dónde viven y cómo se nombran.

## Tareas

- [ ] Fijar el entorno de captura: una base de prueba sembrada con el catálogo de ejemplo, un
      operador ficticio por perfil, resolución y escala declaradas, tema por omisión.
- [ ] Fijar el estado que muestra cada captura. Una pantalla vacía no enseña nada: la de Venta se
      captura con carrito, la de Reportes con datos del período, la de Sync con un enlace real.
- [ ] Fijar la ubicación y el nombre de archivo, uno por pantalla, derivado del identificador de
      la ruta, junto al manual y no disperso en `docs/`.
- [ ] Capturar las quince pantallas y escribir el texto alternativo de cada imagen, que debe
      describir lo que se ve para quien no puede verla.
- [ ] Revisar cada imagen antes de incorporarla: sin PIN, sin token ni cookie, sin clave ni ruta
      de material protegido, sin nombre de una persona o un comercio real, sin identificadores
      que permitan reconstruir un nodo existente.
- [ ] Confirmar que el rótulo fiscal `SIMULACIÓN` es legible en toda captura donde la interfaz lo
      muestra; no se recorta ni se edita la imagen para ocultarlo.
- [ ] Escribir la regla de vigencia: una captura se vuelve a tomar en el mismo hito que cambia la
      pantalla que retrata, con el mismo procedimiento.

## Aceptación

Otra persona, siguiendo el procedimiento, obtiene capturas equivalentes: mismo estado, mismo
encuadre, mismo contenido de ejemplo. Cada imagen tiene texto alternativo útil. Ninguna contiene
material sensible, y la revisión que lo verifica está registrada.

Una captura editada a mano para que se vea mejor de lo que la aplicación se ve no es válida: el
manual describe el producto que existe.
