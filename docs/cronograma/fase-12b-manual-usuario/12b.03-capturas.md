## Preparación reproducible

Desde la raíz del repositorio, con una ruta nueva para cada repetición:

```powershell
$manualRoot = Join-Path (Get-Location) '.data/manual-repeticion'
$env:DATABASE_PATH = Join-Path $manualRoot 'db/node.sqlite'
$env:DATABASE_BACKUP_PATH = Join-Path $manualRoot 'backups'
$env:NODE_KEYSTORE_PATH = Join-Path $manualRoot 'keys'
$env:NODE_IDENTITY_PATH = Join-Path (Get-Location) 'apps/server/config/node-identity.development.json'
$env:RENDERER_DIST_PATH = Join-Path (Get-Location) 'apps/desktop/out/renderer'
$env:FISCAL_EXECUTION_TARGET = 'SIMULATOR'
$env:FISCAL_SIMULATED_REPORT_CONSENT = 'ALLOW_SIMULATED_X_AND_Z'

pnpm --filter @supermarket/server exec tsx src/prepare-development-storage.ts
pnpm --filter @supermarket/server bootstrap-admin
pnpm --filter @supermarket/server bootstrap-operations -- --database $env:DATABASE_PATH --currency USD --discount-max-basis-points 1000 --igtf-basis-points 0 --cash-register-name 'Caja Demo'
pnpm seed:products -- --database $env:DATABASE_PATH --currency USD --tax-rate-basis-points 0
pnpm --filter @supermarket/desktop build
pnpm --filter @supermarket/server start
```

En otra terminal, abrir `pnpm --filter @supermarket/desktop start`. Ingresar con el operador de
prueba y su PIN. No configurar variables `SYNC_*`: esta edición retrata el modo independiente.
Los valores de impuestos, precios y tasa son **datos de demostración**, no valores regulatorios.

Preparar mediante la interfaz o sus contratos públicos, sin modificar tablas ni respuestas:

1. Abrir Caja Demo con USD 50,00 de fondo inicial en efectivo.
2. Crear **Distribuidora Demo**, nombre comercial **Proveedor de práctica**, con la identidad
   fiscal ficticia usada por las pruebas del repositorio (`J-12345678-9`).
3. Recibir 40 unidades de Arroz blanco 1 kg, referencia `MANUAL-001`, con motivo de demostración.
4. Completar una venta de dos unidades de arroz, cobrando USD 3,60 en efectivo. El saldo de
   inventario queda en 38 y el efectivo esperado en USD 53,60.
5. Abrir otro carrito desde Venta con una unidad de arroz y una de harina. Dejarlo sin cobrar:
   total USD 3,20. Descartar el aviso de producto agregado antes de capturar.
6. Contar 38 unidades de arroz y cerrar el conteo, sin aprobarlo: diferencia congelada cero.
7. Registrar una tasa ilustrativa USD/VES de 400,00, fuente **Ejemplo ficticio del manual**, con
   vigencia desde la captura. No solicitar ni usar una cotización externa.
8. Dar de alta **Caja Demo**, **Depósito Demo**, **Gerencia Demo** y **Supervisión Demo** con los
   roles existentes correspondientes, sin generar códigos de enrolamiento para la imagen.
9. Consultar Reportes para el día de las operaciones. La recepción simple no aporta costo:
   el margen debe mostrar **Sin determinar**, no un valor inventado.

Desde la etapa ET, el paso 7 debe quedar hecho **antes** de capturar Caja y Venta, y el mismo
día: sin tasa, Caja muestra el aviso de tasa y la barra de cobro no da el equivalente en
bolívares. Con la tasa de ejemplo, la barra de `06-venta.png` debe mostrar Bs 1.280,00 para el
total de USD 3,20.

Las operaciones de preparación de esta sesión usaron los comandos del proyecto y la API pública.
La navegación, selección de productos y encuadre se hicieron en la PC mediante Computer Use.
Guardar cada captura completa solo cuando hayan terminado las cargas y se haya revisado la imagen.

## Vigencia y límite del guion anterior

Las imágenes viven en `docs/operacion/manual-usuario/capturas/`. Cuando cambie una pantalla,

`pnpm manual:pdf` en el mismo hito.

utilidad para recorrer rutas, pero no prepara estos datos ni reproduce los desplazamientos de
esta sesión. Sus tomas automáticas no sustituyen el procedimiento y la revisión de arriba.
