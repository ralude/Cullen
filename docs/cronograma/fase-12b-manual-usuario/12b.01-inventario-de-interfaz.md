# Sub-fase 12B.01: Inventario verificable de la interfaz

- **Fase:** [Fase 12B — Manual de usuario no técnico](./README.md)
- **Estado:** Planificada el 2026-09-09; ejecución pendiente.
- **Depende de:** nada dentro de 12B. Es el primer corte.

## Objetivo

Fijar, sobre un commit identificado, qué renderiza la aplicación. El manual promete cubrir «todo
lo que la interfaz muestra»; sin una lista comprobable esa promesa no se puede aceptar ni
rechazar, y el primer capítulo que se olvide pasará inadvertido.

## Tareas

- [ ] Recorrer las doce rutas declaradas en `App.tsx` y registrar, por cada una: identificador,
      etiqueta de la barra lateral, título del área de trabajo, descripción que muestra el
      encabezado, atajo y grupo al que pertenece.
- [ ] Registrar las pantallas que existen fuera de la navegación: ingreso, cambio de PIN
      obligatorio y activación de credencial.
- [ ] Registrar el marco de la ventana: grupos de la barra lateral, indicador de conexión con el
      nodo, rótulo fiscal, nombre del operador y botón de salida.
- [ ] Por cada pantalla, listar sus secciones y sus acciones con el texto que el usuario lee, no
      con el nombre del componente.
- [ ] Por cada pantalla, listar sus **estados**: contenido normal, vacío, error y —donde aplique—
      sin turno abierto, sin caja configurada, sin conexión con el nodo.
- [ ] Registrar los componentes compartidos que el usuario percibe como parte de la pantalla:
      buscador de productos, avisos de error y de confirmación, y formato de importes.
- [ ] Publicar el inventario como manifiesto en esta sub-fase, con el commit al que corresponde.

## Aceptación

Cualquier persona puede tomar el manifiesto, abrir la aplicación en el commit indicado y
confirmar que no falta ni sobra una pantalla, una sección ni una acción. El inventario distingue
lo que se ve siempre de lo que aparece solo con cierto permiso o cierto estado, y no incluye
capacidades que no estén en el árbol.

El inventario no es el manual: es la lista contra la que se mide su cobertura. Un recuento de
componentes de React no la sustituye, porque el lector no ve componentes.
